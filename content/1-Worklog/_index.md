This section documents the progress and daily tasks carried out during the 12-week internship at Amazon Web Services Viet Nam under the First Cloud AI Journey (FCAJ) program. The schedule commenced on May 25, 2026, and is recorded from Monday to Friday each week.

The worklog reflects the learning progression from foundational AWS services to hands-on architecture design, deployment, and optimization of the Chatpulse project in alignment with the AWS Well-Architected Framework.

12-week roadmap:

1. [Week 1: Internship orientation, AWS culture, and security foundation setup](1.1-week1/)
2. [Week 2: Amazon VPC networking, EC2 compute, and S3 static storage](1.2-week2/)
3. [Week 3: Cloud databases RDS, DynamoDB, and CloudWatch monitoring](1.3-week3/)
4. [Week 4: Serverless fundamentals, Infrastructure as Code, and Well-Architected Framework](1.4-week4/)
5. [Week 5: Container packaging, CloudFront CDN, and Route 53 DNS](1.5-week5/)
6. [Week 6: Chatpulse project kickoff, requirements analysis, architecture design, and VPC](1.6-week6/)
7. [Week 7: Codebase initialization, backend development, and ElastiCache Redis](1.7-week7/)
8. [Week 8: Real-time chat implementation, direct S3 uploads, and SSL domain setup](1.8-week8/)
9. [Week 9: Security hardening with WAF, IAM, CloudWatch Logs, and CI/CD pipeline](1.9-week9/)
10. [Week 10: UI/UX refinement, end-to-end testing, automated alarms, and demo video](1.10-week10/)
11. [Week 11: Cloud cost optimization, performance benchmarking, and technical blog](1.11-week11/)
12. [Week 12: Project finalization, code refactoring, report completion, and mentor review](1.12-week12/)
