### Recommended Teardown Sequence

To prevent Dependency Violation errors during AWS resource deletion, execute the teardown in the following strict order:

#### 1. Terminate Amazon EC2 Host
1. Open the **Amazon EC2 Console**, navigate to **Instances**.
2. Select `ChatPulse-Backend-Server`, choose **Instance state**, select **Terminate instance**, and confirm deletion.
3. Navigate to **Elastic IPs**, select the static IP `54.254.6.80`, choose **Actions**, and select **Release Elastic IP addresses** to prevent unattached IP charges.

#### 2. Delete Amazon ElastiCache Redis Cluster
1. Open the **Amazon ElastiCache Console**, navigate to **Redis OSS caches**.
2. Select the ChatPulse Redis cache cluster and click **Delete**.
3. Select *No* for Create final backup to trigger immediate cluster termination.

#### 3. Disable & Delete Amazon CloudFront Distribution
1. Open the **CloudFront Console**, select the distribution attached to `ericmai.io.vn`.
2. Click **Disable**, allow 3 to 5 minutes for global edge propagation until the status changes to Disabled.
3. Once Disabled, select the distribution again and click **Delete**.

#### 4. Empty & Delete Amazon S3 Bucket
1. Open the **Amazon S3 Console**, select the bucket hosting frontend static artifacts.
2. Click **Empty**, type `permanently delete` to erase all compiled build assets.
3. Once the bucket is completely empty, click **Delete** to remove the bucket from your account.

#### 5. Delete CI/CD Pipelines with AWS CodePipeline and AWS CodeBuild
1. Open **AWS CodePipeline**, select the project pipeline, and click **Delete pipeline**.
2. Open **AWS CodeBuild**, select Build projects, and click **Delete build project**.
3. Access the **IAM Console** to delete ancillary Service Roles generated by CodeBuild and CodePipeline if no longer needed.

#### 6. Delete AWS WAF Web ACL
1. Open **AWS WAF & Shield**, switch Region to **Global CloudFront**.
2. In the *Associated AWS resources* tab, verify that no CloudFront distributions remain attached.
3. Select the ChatPulse Web ACL and click **Delete**.

#### 7. Clean Up Amazon Route 53 Records
1. Open **Amazon Route 53**, select Hosted Zone `ericmai.io.vn`.
2. Delete active Record A sets pointing to CloudFront and EC2, delete CNAME records used for ACM and SES verification, preserving only the default NS and SOA records.

#### 8. Clean Up Security Groups and CloudWatch Alarms
1. Open the **VPC Console**, navigate to **Security Groups**, and delete custom project security groups including the EC2 Backend Security Group and the ElastiCache Redis Security Group.
2. Open **Amazon CloudWatch**, navigate to **Alarms**, select the CPU threshold alarm configured for the host, and click **Delete** to complete resource teardown.
